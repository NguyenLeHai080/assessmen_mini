# Project process documentation

Nhom nay mo ta cach team phoi hop va quan ly thay doi.

## Noi dung can co

- Git/branch/commit workflow: xem [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md).
- `ownership.md`: code/doc owner va reviewer theo khu vuc.
- `definition-of-ready-done.md`: quality gate truoc dev va truoc release.
- `risks.md`: risk, impact, probability, mitigation va owner.
- `decision-log.md`: link den ADR va product decision.
- `release-calendar.md`: moc QA, freeze va production release.
- `onboarding.md`: setup, quyen truy cap va tai lieu bat dau.

## PR documentation checklist

- PR co Issue ID va requirement ID bi anh huong.
- Business behavior thay doi thi cap nhat `01`/`02`.
- API/data/UI/architecture thay doi thi cap nhat nhom tuong ung.
- Test case, deployment, monitoring va release note da duoc danh gia.
- Docs khong chua secret/PII va link noi bo khong bi hong.
