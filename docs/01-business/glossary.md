# Mini Assessment - Business Glossary

| Thuat ngu | Dinh nghia |
| --- | --- |
| Assessment | Mot bai danh gia gom tieu de, mo ta, status va tap cau hoi |
| Question | Cau hoi thuoc mot assessment |
| Answer | Lua chon tra loi thuoc mot question, co the co score |
| Draft | Trang thai dang soan, khong hien cho public |
| Published | Trang thai san sang cho public doc |
| Archived | Trang thai ngung public nhung van luu cho admin |
| Seed data | Du lieu mau tao tu dong khi activate database rong |
| Reviewer/Lead | Nguoi nhan goi ban giao va kiem tra tren site WordPress moi |
| Admin/Content manager | Nguoi co quyen quan ly noi dung assessment |
| Public viewer | Nguoi dung chua dang nhap chi xem noi dung published |
| Parent/child | Quan he Assessment-Question hoac Question-Answer |
| Sort order | So nguyen quy dinh thu tu hien thi |
| REST namespace | Prefix version cua API, hien tai `assessment/v1` |
| Nonce | Token WordPress chong request gia mao cho thao tac thay doi |
| Bundle/dist | File JS/CSS da build de WordPress load, khong can npm |
| Smoke test | Kiem tra nhanh install, activate, DB, API va UI sau ban giao |
