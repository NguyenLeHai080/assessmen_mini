# UI and UX documentation

Nhom nay mo ta trai nghiem nguoi dung va contract cua tung man hinh.

## Noi dung can co

- `information-architecture.md`: navigation va phan cap noi dung.
- `<feature>-user-flow.md`: entry, action, decision va exit.
- `<screen>-spec.md`: `UI-*`, layout, component, content va interaction.
- `design-system.md`: token, typography, color, spacing va component rule.
- `accessibility.md`: keyboard, focus, contrast, label va screen reader.

## Moi screen/flow phai co

- Related `BR-*`/`FR-*`, actor va permission.
- Loading, empty, success, validation, error va disabled state.
- Responsive behavior va supported browser/device.
- Copy/text, analytics event va API dependency.
- Link den design source va ngay/version duoc review.
