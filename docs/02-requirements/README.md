# System requirements

Nhom nay chuyen business need thanh cac behavior va quality co the kiem chung.

## Noi dung can co

- `functional-requirements.md`: danh sach `FR-*`, input, output va priority.
- `non-functional-requirements.md`: `NFR-*` cho performance, availability,
  scalability, compatibility, accessibility va compliance.
- `use-cases.md`: `UC-*`, actor, precondition, main/alternate flow.
- `acceptance-criteria.md`: Given/When/Then lien ket voi `BR-*`/`FR-*`.
- `dependencies-and-constraints.md`: dependency, assumption va gioi han.

## Tieu chi requirement tot

- Mot nghia, co the test, khong phu thuoc vao cach implementation.
- Co owner, priority, source Issue va ID on dinh.
- Co happy path, validation, permission va exception path.
- NFR co con so/muc tieu; tranh cac tu mo ho nhu `nhanh` hoac `on dinh`.

## Review owner

BA/Product soan noi dung; Tech Lead va QA xac minh kha thi va kha nang test.
